# Contributing

Thanks for your interest. Quick guidelines:

- Fork and open a PR against `main`.
- Keep secrets out of commits; use `.env` and CI secrets.
- Write unit tests for new logic and run `pytest` before submitting.
- For infrastructure changes, explain how to run local smoke tests (`docs/INTEGRATION_CHECKLIST.md`).
# Contributing

Thank you for considering contributing to the Linux Learning Platform.

Guidelines:
- Fork the repository and create feature branches.
- Keep curriculum content separated under `curriculum/`.
- Add labs under `labs/` and validators under `backend/validator/`.
- Run tests (TBD) and lint before opening a PR.

See `docs/ARCHITECTURE.md` for design notes.
