# RHCSA EX200 — Core Mapping (Initial)

This file contains an initial mapping of RHCSA EX200 objectives to curriculum lessons. It is a starting point and will be expanded with lesson content, guided labs, challenge labs, and validators.

Initial topics:

- Managing users and groups
- Managing files and directories, permissions, ACLs
- SELinux basics (enforcing, permissive, troubleshooting)
- Managing services with systemd
- Boot process and troubleshooting
- Managing storage: partitions, LVM, mounting
- Scheduling jobs (cron, systemd timers)
- Network basics: IP config, DNS, SSH
- Package management (dnf/yum, repositories)
- Logging and journald
- Basic shell scripting and tools (grep/sed/awk/find)
- Security: firewalld basics, SSH hardening
- Troubleshooting methodology and scenarios

Each topic will include: concept, why, how, visual, command playground, guided lab, challenge lab, troubleshooting lab, and validator.
